# 1. ASSUNTO

1.1. Conteúdo de exemplo para demonstrar a conversão de documentos ao padrão do editor SEI. Todos os dados abaixo são fictícios.

# 2. ANÁLISE

2.1. O texto abaixo exercita os principais elementos tratados pelo conversor: títulos numerados, listas com marcadores, tabelas e links.

2.2. Elementos verificados nesta conversão:

- Parágrafos justificados com a classe institucional.
- Listas com marcadores convertidas em `<ul>`.
- Tabelas com cabeçalho em cinza e larguras percentuais.

2.3. A tabela a seguir resume os formatos aceitos pela ferramenta:

| Formato | Extensão | Observação |
| --- | --- | --- |
| Word | .docx | Preserva negrito, itálico, tabelas e imagens |
| PDF | .pdf | Remove carimbos e assinaturas do SEI |
| Markdown | .md | Converte títulos, listas e tabelas |
| Texto | .txt | Estrutura parágrafos automaticamente |

2.4. A documentação completa está em [https://github.com/pancoh/conversorsei](https://github.com/pancoh/conversorsei).
